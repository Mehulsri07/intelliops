# Diagrams

Five diagrams, each in a dark and a light variant, generated by
`node scripts/make-diagrams.mjs`.

**Do not hand-edit the SVG.** Edit the generator and regenerate, or the geometry gate below
stops meaning anything.

| File | What it answers |
|---|---|
| `01-architecture` | What the services are, what flows between them, and which call blocks |
| `02-incident-flow` | Alert storm to verified fix, including every exit the system can take |
| `03-recovery-ladder` | What happens when the first fix does not work, and where we stop |
| `04-data-sources` | The three stores and which question each one answers |
| `05-earned-autonomy` | How a playbook reaches unattended execution, and how it loses it |

Open `index.html` to view them all with a theme switch.

## Why a generator rather than Mermaid

These sit in the capstone deck next to slides that were designed, so they have to carry the
product's own palette and type scale. Mermaid's auto-layout cannot be made to do that. The
cost is that layout is manual, which is why the gate exists.

## The geometry gate

SVG has no layout engine. A coordinate that is 80px wrong does not raise an error, it
produces a picture that is quietly unreadable, and the first cut of `01-architecture` shipped
`action` sitting underneath `read model` for exactly that reason.

So every solid box and every arrow label registers its rectangle, and the generator exits
non-zero if any two overlap or anything falls outside the canvas. It has already caught:

- `action` overlapping `read model`
- two boxes running off the right edge of `02-incident-flow`
- the `situations.diagnosed` label being wider than the gap it sat in, so it overprinted the
  node on either side

What the gate does **not** check is whether the result reads well. Look at the diagrams after
regenerating.

## Palette

Lifted from `frontend/src/styles/index.css`, so the diagrams, the console and the deck are
one visual system. If the console's palette changes, update the `THEMES` block at the top of
the generator to match.

Fonts are Arial and Courier New rather than the console's Geist: an SVG in a PowerPoint deck
is rendered by whatever fonts the presenting machine has, and those two are everywhere.
Anything that is a real identifier (a topic, a table, a verb) is set in the mono face.

## Source of truth

The bus topology in `01-architecture` is not drawn from memory. It was read out of the
services:

```
ingestion    publishes  telemetry.raw
correlation  consumes   telemetry.raw        publishes  situations.detected, situations.suppressed
rca          consumes   situations.detected  publishes  situations.diagnosed
action       consumes   situations.diagnosed publishes  remediation.outcomes
feedback     consumes   remediation.outcomes
read         consumes   all four
governance   called by action over HTTP, and that call blocks
```
